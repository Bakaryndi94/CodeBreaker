
# CodeBreaker

Bienvenue sur CodeBreaker !

Ce projet est un jeu de réflexion inspiré de Mastermind. Le joueur doit retrouver une combinaison secrète en utilisant les indices obtenus après chaque tentative.

## Règles du jeu

- Une combinaison secrète est générée au début de la partie.
- Le joueur propose une combinaison.
- Des indices lui permettent de savoir si sa proposition est correcte.
- Le joueur utilise ces indices pour trouver la combinaison secrète.

## Technologies utilisées

- Java
- JavaFX
- FXML
- Maven
- JUnit 5

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/Bakaryndi94/CodeBreaker.git
   ```

2. Ouvrir le projet dans IntelliJ IDEA.
3. Configurer le JDK.
4. Installer les dépendances Maven.
5. Lancer la classe principale `HelloApplication`.
